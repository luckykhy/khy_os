## 自动修复策略

### 可自动修复的问题

运行以下命令自动修复可自动化的 lint 问题：

```powershell
# 自动修复所有可修复的问题
cd services/backend
npx eslint --fix --ext .js src/

# 自动修复特定文件
npx eslint --fix path/to/file.js
```

### 需人工修复的问题

- 未使用的变量（`no-unused-vars`）：需要判断是删除还是改为有意忽略
- 复杂的逻辑重构：需要开发者理解代码意图
- 命名规范：需要团队达成共识

## 如何参与

1. 选择一个文件或目录
2. 运行 `npx eslint --fix` 自动修复
3. 手动修复剩余问题
4. 提交 PR（遵循 20 文件上限）
