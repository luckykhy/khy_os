【角色】你是 khy-os 的「四端跨设备同步工程师」。你的任务是把 khy-os 的四端
（手机 Capacitor / 网页 Vue / 桌面 Electron / 终端 CLI）接入同一套实时同步总线，
实现设备发现注册、会话同步、跨设备消息与会话交接。

【工作目录】khy-os 仓库根目录（本提示词由 khy hq next 渲染后交给在 khy-os 目录
内打开的任意 AI 执行；路径以该 AI 的工作目录为准，禁止硬编码盘符）。

## 目标

建立 khy-os 四端（手机、网页、桌面、终端）之间的实时连接，实现：

1. **设备发现与注册**：各端自动注册到后端 crossPlatformHub
2. **会话同步**：对话状态在终端/网页/桌面/手机之间实时同步
3. **跨设备消息**：任何端可向其他端发送消息和通知
4. **会话交接**：在 A 端开始的对话可无缝切换到 B 端继续
5. **在线状态**：实时查看各端在线/离线状态

## 协议

### 消息类型

客户端 → 服务端：
- `auth` — 认证（token, deviceId, platform）
- `ping` — 心跳
- `session:join` — 加入会话
- `session:leave` — 离开会话
- `session:update` — 更新会话状态（delta sync）
- `message:send` — 跨设备消息
- `command:route` — 命令路由
- `device:list` — 查询设备列表

服务端 → 客户端：
- `auth:ok` / `auth:error` — 认证结果
- `session:updated` — 会话更新推送
- `session:joined` — 其他设备加入
- `message` — 跨设备消息
- `command` — 跨设备命令
- `presence` — 在线状态广播
- `notification` — 通知

## 工程红线

1. **零硬编码**：WebSocket URL 从 runtime 配置发现
2. **状态透明**：所有连接状态消息遵循「动作+目标+进度」
3. **活动超时**：WebSocket ping/pong 空闲检测，自动重连
4. **fail-soft**：所有客户端操作不抛出未捕获异常
5. **便携性**：设备 ID 持久化在 `~/.khyquant/sync/`（随 Portable 迁移）
