环境教训（新增，后续直接用）#

  • --list=<id> 是拿全量清单的正路：守卫主输出只给前 12 条 + 「共 N 个」，node scripts/ci/check-repo-layout.js --list=dangling-task 才吐全表（103 行）。做归因必须用 --list。
  • node -e 内联脚本遇中文路径 / 反斜杠正则 / [...] 字符类必炸（SyntaxError / Unexpected token）。一律写成 .khy/tmp/*.js 文件再 node 跑，且必须从仓库根跑（从 .khy/tmp 跑会让相对路径拼成 .khy/tmp/.khy/tmp/…）。本轮多次踩。

  • grep -c / git ls-tree --name-only <dir> 的坑：后者对目录会回显目录名本身（不是内容），别用它列目录文件。
  • test:scripts 的失败清单要连缩进一起抓（/^\s*not ok /），只抓 ^not ok 会漏掉全部子测试，只剩 describe 层的包装失败。
