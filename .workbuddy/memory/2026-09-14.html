结论 1：AI 通道不是「密钥失效」，是健康判定误判（高价值）#

  • 直接探测：POST https://apihub.agnes-ai.com/v1/chat/completions，用 .khy/api_keys.json 里的 agnes key，

agnes-2.5-flash 与 agnes-3.0-flash 均返回 HTTP 200（有正常 completion）。

  • 同一 key 打 GET /v1/models → HTTP 404（agnes 未实现该端点）。
  • 因此「key 过期 / 需修复 key」是错误结论；方向应在 apiAdapter.detectAsync（:251 用 /models 探测）

与失败分类 / 回退顺序：把 /models 404 当作通道不可用，会直接把请求降级到 codex 并输出
codex [unavailable]: OpenAI Codex unavailable。

  • 旁证：khy doctor 报 ⚠ AI 密钥 — 未配置、⚠ API 云端服务 运行时诊断 — 通道异常(404)，未触发自愈；

.khy/last_verified_model.json 显示 09-14 09:26 还验证通过过 agnes-2.5-flash。

  • 影响面：每日 13:00 对齐流水线（对齐/待办与进度/2026-07-11_claude_code_vs_khyos对齐任务单.md）
