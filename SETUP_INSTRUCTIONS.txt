🎯 请按照以下步骤操作：

步骤 1️⃣：打开 PowerShell
─────────────────────────────────────────────────────────
  方法 A：按 Win + X，选择"Windows PowerShell"
  方法 B：在开始菜单搜索"PowerShell"并打开
  
  ⚠️ 不需要管理员权限，普通用户即可！

步骤 2️⃣：进入项目目录
─────────────────────────────────────────────────────────
  cd C:\khy-os

步骤 3️⃣：运行配置脚本
─────────────────────────────────────────────────────────
  .\setup-khy-command.ps1
  
  如果提示执行策略错误，运行：
  Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
  然后再次运行：.\setup-khy-command.ps1

步骤 4️⃣：按提示操作
─────────────────────────────────────────────────────────
  • 如果询问是否覆盖，输入 y
  • 如果询问是否立即重载，输入 y

步骤 5️⃣：测试
─────────────────────────────────────────────────────────
  khy --version
  khy --help

✅ 如果显示版本号 1.1.9，说明配置成功！

═══════════════════════════════════════════════════════════════

🔧 备用方案（如果脚本执行遇到问题）：

手动配置（3 步）：
  1. 在 PowerShell 中运行：notepad $PROFILE
  2. 添加这一行：
     function khy { node C:\khy-os\services\backend\bin\khy.js $args }
  3. 保存，关闭 PowerShell，重新打开，测试：khy --version
