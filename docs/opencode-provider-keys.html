快速配置指南#

在其他电脑上配置时，只需在 opencode.json 的 provider 字段中添加对应条目：

{
  "provider": {
    "<provider-id>": {
      "api": "openai",
      "name": "显示名称",
      "options": {
        "apiKey": "你的API Key",
        "baseURL": "API地址"
      },
      "models": {
        "model-id": {
          "id": "model-id",
          "name": "显示名称"
        }
      }
    }
  }
}

切换模型：在 opencode 中输入 /model 然后选择 provider-id/model-id
