🚀 快速启动指南#

方式 1：使用便携启动器（推荐）#

# Windows
.\khy.bat

# Linux/macOS  
./khy.sh

启动器会自动：

  • 检测 Python 和 Node.js 环境
  • 拉起后端服务
  • 进入 CLI 交互模式

方式 2：直接启动后端#

cd services/backend
npm start          # 生产模式
# 或
npm run dev        # 开发模式（热重载）

后端服务默认运行在：http://localhost:5000

方式 3：启动前端开发服务器#

cd apps/ai-frontend
npm run dev

前端开发服务器默认运行在：http://localhost:3000

API 请求会自动代理到后端 http://localhost:5000

方式 4：CLI 模式#

cd services/backend
npm run cli

直接进入 Khy-OS 命令行界面。

🔧 首次运行配置#

1. 环境变量（可选）#

前端环境变量（如需自定义）：

cd apps/ai-frontend
cp .env.example .env.local
# 编辑 .env.local 配置 API 地址等

后端环境变量（如需配置数据库等）：

cd services/backend
# 创建 .env 文件
# 配置数据库连接、API 密钥等

2. 数据库初始化（如使用 PostgreSQL）#

cd services/backend
npm run migrate    # 运行数据库迁移
npm run seed       # 填充种子数据

3. 默认管理员账号#

首次启动后端时会自动创建默认管理员账号。

查看默认密码：

# Windows
type %USERPROFILE%\.khy\credentials\default-admin.json

# Linux/macOS
cat ~/.khy/credentials/default-admin.json

或在后端启动日志中查看输出的账号信息。
