# [OPS-MAN-209] AI 供应商接入族总纲

> **定位**：本文件是 `docs/07_OPS_运维/` 中 **AI 供应商接入族**（把任意模型供应商接进 khy 网关）的唯一导航入口与 scope 裁决真源。
> 本族共 **4 篇 + 1 邻接**，按「配置入口 → 接入流程 → 对账」三层分工（§1–§2）——**不合并文档，而是收敛为一个入口**。
> **生成层边界**：`096` 由 `node scripts/model-type-providers.js --gen-doc` 生成（带「请勿手改」banner），
> 属生成层；`032` / `172` / `205` 为手写层，已各自加「隶属」头。
> **代码真源**：一键预设清单的真源是 `services/backend/src/services/gateway/providerPresets.js`，
> 预设端点默认值在 `services/backend/src/constants/serviceDefaults.js`。
> 本族只回答「**怎么接**」；端点/模型清单的**数值真源在代码**，文档过期时以代码为准。
> **适用边界**：只覆盖「供应商接入与配置」；模型调用链、降级熔断见 `[DESIGN-GW-002]`，管理页 UI 见 `[OPS-MAN-002]` / `[OPS-MAN-003]`。

## 0. 一分钟导读（按意图分流）

| 你想做什么 | 直接读 |
| --- | --- |
| 只填一个 API Key，最快跑起来 | `205` API 厂商快速配置指南 |
| 接一个**任意**自定义 Provider（完整流程） | `172` 自定义供应商接入指南 |
| 从 **Web / TUI / 命令行** 某个具体入口接入 | `032` 网关·自定义 Provider 配置（Agnes 为例） |
| 查四类模型各自在**哪个 env 命名空间**解析 provider | `096` 多模型类型 Provider 配置对账（生成层） |
| 查模型配置的**书写风格**惯例 | 邻接：`010` Hermes 风格模型配置 |

## 1. 三层全景

| 层 | 职能 | 成员（编号） | 篇数 | 层性 |
| --- | --- | --- | --- | --- |
| **L1 速配** | 厂商 Key 速配，一步到位 | `205` | 1 | 手写 |
| **L2 流程** | 任意 Provider 的端到端接入（预设 + 手动 + 命令） | `172` `032` | 2 | 手写 |
| **L3 对账** | 多模型类型的 env 命名空间对账 | `096` | 1 | **生成** |

## 2. 各层详情

### L1 · 速配（1 篇）
| 编号 | 职责 | 行数 |
| --- | --- | --- |
| `205` | API 厂商快速配置——现在只需输入 API Key，khyos 自动完成其余配置；覆盖主流厂商 | 279 |

### L2 · 接入流程（2 篇）
| 编号 | 职责 | 行数 |
| --- | --- | --- |
| `172` | **族内流程最全**的一篇：一键预设 + 手动编辑 `custom_providers.json` + `serviceType` 取值 + `khy gateway add` + `model_overrides.json` 默认模型切换 + Key 获取与 `env` 端点覆盖 | 214 |
| `032` | **按入口**切入的一篇：Web 前端 / khy TUI / 命令行三条入口各怎么接（以 Agnes 为例，适用于任意 OpenAI 兼容 Provider） | 204 |

> `172` 与 `032` **不合并**：前者按「配置手段」组织（预设/手动/命令），后者按「使用入口」组织（Web/TUI/CLI），
> 是同一件事的**两种索引维度**，读者来路不同。合并会逼读者在两种组织方式里二选一。

### L3 · 对账（1 篇，生成层）
| 编号 | 职责 | 行数 |
| --- | --- | --- |
| `096` | 四类用户可见模型分别在互不相通的 env 命名空间里解析 provider 的对账表 | 41 |

> **不可手改**：由 `scripts/model-type-providers.js --gen-doc` 生成，改动须改生成器后重跑。

## 3. scope 裁决

| 议题 | 裁决 | 依据 |
| --- | --- | --- |
| 「接入族」到底几篇 | **4 篇**（`032`/`096`/`172`/`205`） | 实测：方案 `[MGMT-PLAN-009]` §1.2 原列的 6 篇中，`002`（AI 管理页 NewAPI 对齐——UI 对比度）与 `003`（管理页访问与登录）**主题不符**，已剔出；实测另补入 `096`。 |
| 是否物理合并 | **否** | 三层职责不同（速配 / 流程 / 对账），且 `096` 是生成层产物；DR1 禁删、DR8 要求先验生成器幂等。 |
| 端点/模型清单以谁为准 | **代码** | `providerPresets.js` / `serviceDefaults.js` 是数值真源；文档只描述「怎么填」。 |
