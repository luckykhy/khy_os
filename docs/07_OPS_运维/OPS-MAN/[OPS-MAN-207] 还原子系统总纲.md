# [OPS-MAN-207] 还原子系统总纲

> **定位**：本文件是 `docs/07_OPS_运维/` 中**还原子系统**（restore）的唯一导航入口与 scope 裁决真源。
> 本族共 **23 篇**，分 5 组（§1–§2）；其中 **18 篇由 `scripts/restore/*.js --gen-doc` 确定性生成**、5 篇手写（§3）。
> **硬约束（DR7）**：18 篇生成文档的路径与编号被 `scripts/restore/*.js` 当作**代码常量**引用，**禁止移动或重命名**；本批次只加导航、不动路径。
> **适用边界**：只覆盖「离机还原」这一子系统的运维文档；还原实现代码见 `scripts/restore/`，还原运行时接线见 117/119/130。

## 2. 各组详情

### 组 1 · 离机渠道与安装后还原

## 4. Scope 裁决（依据 `[MGMT-STD-008]` §2.2「重叠即违规」）

- **三面镜子三篇不合并**（`076`/`079`/`082`）：三阶段、三脚本、三套判据，属**同源异构**而非重复。
- **五篇对账不合并**：对账对象互斥。
- **生成层与手写接线层不合并**：前者是判据，后者是运行时落点，读者不同。
- 本族与 `[OPS-MAN-066]`（进化提示词）、`[OPS-MAN-067]`（症状分诊）**边界清晰**，互不覆盖。
