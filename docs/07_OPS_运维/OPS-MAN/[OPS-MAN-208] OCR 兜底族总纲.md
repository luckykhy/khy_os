# [OPS-MAN-208] OCR 兜底族总纲

> **定位**：本文件是 `docs/07_OPS_运维/` 中 **OCR 兜底族**（纯文本模型读图的兜底链路）的唯一导航入口与 scope 裁决真源。
> 本族共 **17 篇**，按职能分 **3 组**（§1–§2）——即原「17 → 3」的收敛口径：**不合并文档，而是收敛为一个入口 + 三个职能组**。
> **硬约束（DR7）**：`127`/`138`/`140`/`148` 被 `services/backend/src/services/flagRegistry.js` 引用，
> `132`/`142`/`144`/`148` 被 `services/backend/src/services/gateway/aiGatewayGenerateMethod.js` 引用，
> `126` 见于 `scripts/ci/debt-ledger.json`。**这些编号被代码当标识用，禁止移动或重命名**；本批次只加导航。
> **适用边界**：只覆盖「OCR 兜底」的用户可见行为与诚实性约束；OCR 引擎本身的能力与选型不在本族。

## 0. 一分钟导读（按意图分流）

| 你想做什么 | 直接读 |
| --- | --- |
| 查 OCR **兜底能做到什么、边界在哪** | 组 1：`104` `109` `111` `112` `115` `116` `118` `120` |
| 查**怎么告诉用户「用了 OCR」** | 组 2：`124` `126` `127` `132` |
| 查**模型谎称没收到图怎么纠正** | 组 3：`138` `140` |
| 查**怎么减少「心灵噪音」**（失败墙/闭合/去重） | 组 3：`142` `144` `148` |

## 1. 三组全景

| 组 | 职能 | 成员（编号） | 篇数 |
| --- | --- | --- | --- |
| **1** | **兜底能力与质量边界**——OCR 能兜住什么、哪些情况必须诚实告知 | `104` `109` `111` `112` `115` `116` `118` `120` | 8 |

## 2. 各组详情

### 组 1 · 兜底能力与质量边界（8 篇）
| 编号 | 职责 |
| --- | --- |
| `104` | 低置信诚实告诫——置信度不足时必须如实说 |
| `109` | 覆盖率诚实告诫——覆盖率不足时不得假装全读到 |
| `111` | 截断诚实告诫——结果被截断时须声明 |
| `112` | 语言包可用性诚实告诫——语言包缺失时须声明 |
| `115` | 方向自动校正（兜底能力增强） |
| `116` | 低分辨率自动放大（兜底能力增强） |
| `118` | 视觉描述级联**全失败**时的 OCR 兜底底线解耦 |
| `120` | 剥图必留痕最小底线与 OCR 功能门解耦 |

> 前四篇（104/109/111/112）是**同一类「诚实告诫」**的四个不同触发面（置信度 / 覆盖率 / 截断 / 语言包），
> **不合并**：触发条件与判据各自独立，合并会丢失判据边界。

### 组 2 · 告知与透明度（4 篇）
| 编号 | 职责 |
| --- | --- |
| `124` | OCR 成功路径向用户**透明告知**用了 OCR |
| `126` | 成功路径的**确定性脚注**兜底告知 |
| `127` | 救援网成功时的**实时状态**告知已降级到 OCR（**代码引用**：flagRegistry） |
| `132` | prep 期 OCR 兜底**非 verbose** 实时状态告知（**代码引用**：aiGatewayGenerateMethod） |

> 124/126 是「事后告知」，127/132 是「过程实时状态」，两者读者与时机不同，**不合并**。

### 组 3 · 纠正与降噪（5 篇）
| 编号 | 职责 |
| --- | --- |
| `138` | 空 OCR 剥图路径下模型仍谎称没收到图的**确定性纠正脚注**（**代码引用**：flagRegistry） |
| `140` | OCR 成功读出但模型仍谎称没收到图的**确定性纠正脚注**（**代码引用**：flagRegistry） |
| `142` | 失败墙推迟到 OCR 结果已知后，减少心灵噪音（**代码引用**：aiGatewayGenerateMethod） |
| `144` | describe-fail 到 OCR 成功的**用户可见闭合**，减少心灵噪音（**代码引用**：aiGatewayGenerateMethod） |
| `148` | Site1-prep 状态与 OCR 成功闭合的**跨层去重**，减少心灵噪音（**代码引用**：两处） |

> 138/140 是「模型撒谎的纠正」，142/144/148 是「减少用户心理负担」，职能不同但同属「失败态体验」，归为一组。

## 4. Scope 裁决（依据 `[MGMT-STD-008]` §2.2）

- **四篇诚实告诫不合并**（104/109/111/112）：触发面互斥，判据独立。
- **124 与 126 不合并**：一个是透明告知策略，一个是脚注兜底实现，层次不同。
- 本族与**还原子系统**（总纲 `[OPS-MAN-207]`）**边界清晰**：本族管读图兜底，还原族管离机还原，互不覆盖。
- 本族 17 篇**全部手写**（无 `--gen-doc` 生成器），可直接编辑；已统一加「隶属」头。
