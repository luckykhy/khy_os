[OPS-MAN-209] AI 供应商接入族总纲#

定位：本文件是 docs/07_OPS_运维/ 中 AI 供应商接入族（把任意模型供应商接进 khy 网关）的唯一导航入口与 scope 裁决真源。
本族共 4 篇 + 1 邻接，按「配置入口 → 接入流程 → 对账」三层分工（§1–§2）——不合并文档，而是收敛为一个入口。
生成层边界：096 由 node scripts/model-type-providers.js --gen-doc 生成（带「请勿手改」banner），
属生成层；032 / 172 / 205 为手写层，已各自加「隶属」头。
代码真源：一键预设清单的真源是 services/backend/src/services/gateway/providerPresets.js，
预设端点默认值在 services/backend/src/constants/serviceDefaults.js。
本族只回答「怎么接」；端点/模型清单的数值真源在代码，文档过期时以代码为准。
适用边界：只覆盖「供应商接入与配置」；模型调用链、降级熔断见 [DESIGN-GW-002]，管理页 UI 见 [OPS-MAN-002] / [OPS-MAN-003]。
