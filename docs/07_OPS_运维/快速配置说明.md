# ⚡ API厂商快速配置

## 一行命令，输入Key即可

```bash
khy gateway
```

选择：
```
⚡ 快速配置API厂商 (输入Key即可)
```

## 支持的厂商

| 厂商 | 说明 |
|------|------|
| DeepSeek | 深度求索 - 对话/代码/推理 |
| 通义千问 (Qwen) | 阿里云 - turbo/plus/max |
| 智谱 GLM | 智谱AI - 免费模型丰富 |
| 豆包 (Doubao) | 字节跳动 - pro/lite |
| 百度文心 | 百度 - ernie-4.0/speed |
| OpenAI | GPT系列 - gpt-4o/mini |
| Anthropic (Claude) | Claude系列 - sonnet/haiku |
| Trae API | Trae编码助手 |

## 使用流程

### 1. 运行命令
```bash
khy gateway
```

### 2. 选择厂商
```
选择要配置的厂商:
❯ DeepSeek (DEEPSEEK_API_KEY)
  通义千问 (Qwen) (QWEN_API_KEY)
  智谱 GLM (GLM_API_KEY)
  ...
```

### 3. 输入API Key
```
请输入DeepSeek API Key: ********
```

### 4. 选择默认模型
```
选择默认模型:
❯ deepseek-chat
  deepseek-coder
  deepseek-reasoner
```

### 5. 完成！
```
✅ 配置成功！
```

## 自动配置的内容

- ✅ API密钥 (`{PROVIDER}_API_KEY`)
- ✅ API端点 (`{PROVIDER}_API_ENDPOINT`)
- ✅ API池映射 (`GATEWAY_API_POOL_SERVICE_MAP`)
- ✅ 默认模型 (`GATEWAY_API_POOL_DEFAULT_MODEL_MAP`)
- ✅ 模型路由 (`PROXY_MODEL_ROUTE_MAP`)

## 使用模型

配置完成后，直接使用：

```bash
khy "你好，请介绍一下自己"
```

或选择特定模型：

```bash
khy /model deepseek-chat
khy "使用DeepSeek回答"
```

## 验证配置

```bash
khy gateway status
```

## 故障排除

### API Key无效
- 检查Key是否正确
- 确认Key已激活
- 检查是否过期

### 模型不存在
```bash
khy /model  # 查看可用模型
```

### 网络连接失败
```bash
khy gateway config  # 配置代理
```

## 相关命令

- `khy gateway` - 网关配置
- `khy gateway status` - 查看状态
- `khy /model` - 选择模型
- `khy "问题"` - 直接对话

---

**提示**: 配置完成后需要重启khy命令才能生效。
