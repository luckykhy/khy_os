使用流程#

1. 运行命令#

khy gateway

2. 选择厂商#

选择要配置的厂商:
❯ DeepSeek (DEEPSEEK_API_KEY)
  通义千问 (Qwen) (QWEN_API_KEY)
  智谱 GLM (GLM_API_KEY)
  ...

3. 输入API Key#

请输入DeepSeek API Key: ********

4. 选择默认模型#

选择默认模型:
❯ deepseek-chat
  deepseek-coder
  deepseek-reasoner

5. 完成！#

✅ 配置成功！

自动配置的内容#

  • ✅ API密钥 ({PROVIDER}_API_KEY)
  • ✅ API端点 ({PROVIDER}_API_ENDPOINT)
  • ✅ API池映射 (GATEWAY_API_POOL_SERVICE_MAP)
  • ✅ 默认模型 (GATEWAY_API_POOL_DEFAULT_MODEL_MAP)
  • ✅ 模型路由 (PROXY_MODEL_ROUTE_MAP)

使用模型#

配置完成后，直接使用：

khy "你好，请介绍一下自己"

或选择特定模型：

khy /model deepseek-chat
khy "使用DeepSeek回答"

验证配置#

khy gateway status

故障排除#

API Key无效#

  • 检查Key是否正确
  • 确认Key已激活
  • 检查是否过期

模型不存在#

khy /model  # 查看可用模型

网络连接失败#

khy gateway config  # 配置代理

相关命令#

  • khy gateway - 网关配置
  • khy gateway status - 查看状态
  • khy /model - 选择模型
  • khy "问题" - 直接对话

提示: 配置完成后需要重启khy命令才能生效。
