一、分类内容边界#

本目录（docs/11_报告/）收容一次性人工快照报告（写完即冻结、不再维护的诊断/规模/调研报告）
与少量调研件；机器生成的 JSON 快照一律归 metrics/ 子目录，不再与人工报告混排。
历史/ 子目录存放已归档的一次性报告；metrics/ 存放机器快照（含历史时间戳快照）。

2026-09-15 整理：9 份 技能*.json 快照移入 metrics/；历史/fix_diff.txt（44 行临时 diff 片段）与历史/stash_patch.txt（137,128 行 / 5.4 MB 的 git stash 转储）已删除——两者是 git 临时制品，非文档，后者属仓库体积膨胀源。

边界：现行手册、指南、规范不放这里——它们归对应的 NN_STAGE_中文/ 阶段目录。
判据是「这份文档还会不会被更新」：会更新的是手册，不会更新的是快照。
