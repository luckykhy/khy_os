## 6. 记忆创建快速指南

### 6.1 使用模板

1. **选择模板**：根据记忆类型选择合适模板
2. **复制模板**：复制模板内容到新文件
3. **填写信息**：替换 `[占位符]` 为实际信息
4. **保存文件**：保存到 `.khy/memory/` 目录

### 6.2 命名规范

**文件命名**：
```
<type>_<name>_<hash>.md
```

**示例**：
- `user_basic-profile_a1b2c3d4.md`
- `project_khy-os-architecture_e5f6g7h8.md`
- `feedback_response-style_i9j0k1l2.md`

### 6.3 内容规范

**必须字段**：
- `name`: 记忆名称（唯一标识）
- `description`: 一行摘要（用于检索）
- `type`: 语义类型
- `tier`: 保留层级
- `updated`: 更新时间

**内容要求**：
- 使用中文描述
- 结构化格式（列表、表格）
- 简洁明了
- 避免冗余

## 7. 模板使用示例

### 7.1 创建用户记忆

```bash
# 1. 复制模板
cp docs/03_DESIGN_设计/\[DESIGN-MEM-003\]\ 记忆模板库.md .khy/memory/user_basic-profile_$(uuidgen | cut -c1-8).md

# 2. 编辑文件
vim .khy/memory/user_basic-profile_*.md

# 3. 填写信息
# 替换 [用户称呼] 为实际称呼
# 替换 [主要工作领域] 为实际领域
```

### 7.2 创建项目记忆

```bash
# 1. 使用命令创建
/remember --type project --name "khy-os 架构" --desc "khy-os 项目架构约定" 使用 L0-L6 分层架构，2 空格缩进，单引号

# 2. 或手动创建
cat > .khy/memory/project_khy-os-architecture_$(uuidgen | cut -c1-8).md << EOF
---
name: project-khy-os-architecture
description: khy-os 项目架构约定
type: project
tier: cross_session
updated: $(date -u +"%Y-%m-%dT%H:%M:%S.000Z")
---

## 项目架构
- 目录结构：L0-L6 分层架构
- 代码风格：2 空格缩进，单引号
- 命名规范：camelCase（JS），snake_case（Python）
- 错误处理：try/catch + printError()
EOF
```
