## 1. 关键设计模式

### 1.1 滚动/复制/历史分离（Claude Code 核心模式）

**问题**：滚动、复制、历史回溯不能互相干扰。

**解决方案**：

| 模式 | 触发 | 行为 | 不影响 |
|------|------|------|--------|
| **浏览模式** | 默认 | `↑/↓` 浏览历史输入，`PageUp/Down` 滚动 | 选择/复制 |
| **选择模式** | `v` 进入 | `↑/↓` 选择文本，`y` 复制 | 滚动/历史 |
| **历史模式** | `Ctrl+R` | 搜索历史输入 | 选择/复制 |
| **复制模式** | `c` 进入 | 选择后 `Enter` 复制 | 滚动/历史 |

**实现要点**：
- 模式状态机：每个模式有独立的状态和键位映射
- 模式指示器：状态栏显示当前模式
- `Esc` 退出当前模式，返回浏览模式

### 1.2 视图栈（View Stack）

**模式**：`Esc` 始终返回上一层视图。

```
主对话 → Agent 列表 → Agent 详情 → 日志详情
   ↑         ↑          ↑         ↑
   └─────────┴──────────┴─────────┘
              Esc 返回
```

**规则**：
- 每个视图保存自己的状态（滚动位置、光标、过滤器）
- 返回时恢复状态
- 全局快捷键（`?`、`q`、`Ctrl+P`）在所有视图中工作

### 1.3 命令面板（Command Palette）

**触发**：`Ctrl+P`

**模式**：
1. 输入实时过滤
2. `↑/↓` 导航
3. `Enter` 执行
4. `Esc` 关闭
5. 显示快捷键提示

### 1.4 撤销/重做（Undo/Redo）

**两种实现**：

| 方法 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **操作栈** | 精确撤销 | 实现复杂 | 编辑器类 |
| **状态快照** | 简单 | 粒度粗 | 对话类 |

**Claude Code 风格**：状态快照（检查点）

### 1.5 破坏性操作确认

| 级别 | 触发 | 确认方式 |
|------|------|----------|
| **轻** | 删除单个文件 | `y/N` 提示 |
| **中** | 删除多个文件 | 显示数量确认 |
| **重** | 删除生产数据 | 输入名称确认 |

### 1.6 剪贴板（OSC 52）

```javascript
// 复制到剪贴板（支持 SSH）
function copy(text) {
  const base64 = Buffer.from(text).toString('base64');
  process.stdout.write(`\x1B]52;c;${base64}\x07`);
  // Fallback: pbcopy / xclip / clip
}
```

## 2. 滚动不干扰选择的实现

### 2.1 模式状态机

```
                    ┌──────────┐
                    │ BROWSE   │ ← 默认
                    └────┬─────┘
                         │
          ┌──────────────┼──────────────┐
          │              │              │
          ▼              ▼              ▼
    ┌──────────┐  ┌──────────┐  ┌──────────┐
    │ SELECT   │  │ HISTORY  │  │ COPY     │
    │ (v)      │  │ (Ctrl+R) │  │ (c)      │
    └────┬─────┘  └────┬─────┘  └────┬─────┘
         │              │              │
         └──────────────┼──────────────┘
                        │
                       Esc
                        │
                        ▼
                  ┌──────────┐
                  │ BROWSE   │
                  └──────────┘
```

### 2.2 滚动实现（保留终端滚动历史）

```javascript
// 使用 ED0 而非 ED2 — 保留滚动历史
process.stdout.write('\x1B[0J');  // 清除光标到末尾（保留历史）
// ❌ process.stdout.write('\x1B[2J');  // 全屏清除（擦除历史）

// 保存/恢复光标位置
process.stdout.write('\x1B7');  // 保存光标
process.stdout.write('\x1B[10;1H');  // 移动到第 10 行第 1 列
process.stdout.write('内容');
process.stdout.write('\x1B8');  // 恢复光标
```

  copied 42 chars        ← 3 秒后自动消失
  copied 3 lines
  copied JSON (1.2KB)
  copy failed (no clipboard)

## 3. 执行偏差处理（综合方案）

### 3.1 偏差检测矩阵

| 偏差类型 | 检测方式 | 自动响应 | 用户选项 |
|----------|----------|----------|----------|
| 工具失败 | error 返回 | 显示错误 + 建议 | 重试/跳过/编辑 |
| 工具超时 | 计时器 | 显示超时 | 增加超时/跳过 |
| 循环检测 | 重复调用计数 | 警告 | 中断/继续 |
| 上下文溢出 | token 计数 | 警告 | 压缩/新建 |
| 权限拒绝 | 用户拒绝 | 显示原因 | 修改权限 |
| 模型无响应 | 心跳超时 | 重试 | 切换模型 |

### 3.2 检查点机制

```
执行计划时：
  1. 每个步骤前创建检查点
  2. 步骤成功 → 继续
  3. 步骤失败 → 回滚到上一个检查点
  4. 用户可选择：重试/跳过/修改/中断
```

### 3.3 用户引导纠正

```
当模型跑偏时：

  ⚠ The model seems to be going off track.

  Current action: Reading the same file repeatedly

  [Send guidance]  ← 用户输入纠正指令
  [Interrupt]      ← 中断执行
  [Let it continue] ← 继续观察
  [Rollback]       ← 回滚到检查点
```

## 4. 最佳实践总结

### 4.1 必须遵守

1. **滚动用 ED0 不用 ED2** — 保留终端滚动历史
2. **保存/恢复光标** — 局部更新不闪烁
3. **resize 防抖 50ms** — 避免频繁重绘
4. **批量更新 16ms** — 60fps 流畅渲染
5. **React.memo 所有纯组件** — 减少 50%+ 重绘
6. **OSC 52 剪贴板** — 支持 SSH
7. **操作栈/检查点** — 破坏性操作可撤销
8. **模式分离** — 滚动/选择/历史互不干扰

### 4.2 性能底线

| 指标 | 目标 | 测量 |
|------|------|------|
| 冷启动 | < 100ms | 命令执行到首帧 |
| 热启动 | < 50ms | 有缓存时 |
| 帧率 | ≥ 30 FPS | 流式输出 |
| 输入延迟 | < 16ms | 按键到响应 |
| 内存 | < 50MB | 运行时 |

### 4.3 用户体验

1. **即时反馈** — 所有操作 3 秒内给出反馈
2. **错误可操作** — 错误消息包含修复建议
3. **快捷键可发现** — 底部提示 + `?` 帮助
4. **状态可见** — 模式、进度、连接状态清晰
5. **恢复容易** — 中断后可恢复，破坏性操作可撤销
