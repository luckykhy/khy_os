## 1. 防御纵深 (Defense-in-depth)

### 一句话定义
**不依赖单一防护点——每层都假设上层可能失效。**

### 实例: chatErrorGuard 三层防御

```
JSON.parse 失败
  ↓
Layer 1: try/catch 捕获
  ↓
Layer 2: safeJsonParse 修复截断 JSON
  ↓
Layer 3: chatErrorGuard 兜底,标记 retryable
  ↓
toolUseLoopCore 检测 retryable → 自动重试
  ↓
重试仍失败 → 诚实返回错误 + 继续提示
```

### 适用场景
- 所有外部输入(JSON、SSE、用户输入)的解析
- 网络调用、子进程调用
- 任何可能"万一"失败的地方

### 反模式警示
```javascript
// 错误: 只靠一层 try/catch
try { return JSON.parse(str); } catch { return {}; }

// 正确: 多层兜底
try { return JSON.parse(str); }
catch {
  return safeJsonParse(str, {}); // 修复后再试
}
```

## 2. 纯叶子模式 (Pure Leaf)

### 一句话定义
**函数只做计算,不做副作用;零 IO、确定性、绝不抛。**

### 契约模板
```javascript
'use strict';

/**
 * moduleName.js — 一句话职责。
 *
 * 契约 (CONTRACT):零 IO、确定性、绝不抛、单一真源、可单测。
 *   env 门控 KHY_XXX(默认开,门关即字节回退)。
 */
```

### 四要素
| 要素 | 含义 | 检测方式 |
|------|------|----------|
| 零 IO | 不碰 fs/网络/子进程 | `check-leaf-contract.js` 机器强制 |
| 确定性 | 同输入同输出,无 `Date.now()`/`Math.random()` | 测试 + 人工审查 |
| 绝不抛 | 坏输入→安全默认(`null`/`{ok:false}`/fallback) | 测试覆盖 |
| 可单测 | 无隐藏状态,纯入参出参 | `node:test` |

### 机器守卫
```bash
node scripts/ci/check-leaf-contract.js --changed
```

## 3. 自愈优先于报错 (Self-heal > Error)

### 一句话定义
**瞬时错误自己吞掉重试,永久错误诚实报告+可操作诊断。**

### 错误分类决策树

```
错误发生
  ↓
是瞬时的吗? ─── 是 → 重试(有界) → 成功 → 用户无感知
  ↓                              → 失败 → 降级/诚实报错
  否
  ↓
诚实报错 + 具体诊断 + 继续提示
```

### 瞬时 vs 永久判定

| 类型 | 瞬时(可重试) | 永久(诚实报错) |
|------|-------------|---------------|
| 网络 | ECONNRESET, ETIMEDOUT, socket hang | 无效 URL, DNS 永久失败 |
| JSON | 截断 fragment, 畸形 JSON | 协议不兼容, 返回非 JSON |
| 服务 | 500/502/503 瞬时抖动 | 401 凭据失效, 403 权限不足 |
| 工具 | 超时, 临时 IO 错误 | 参数错误, 依赖缺失 |

### 自愈中间件
```javascript
const { withSelfHealing } = require('./gateway/selfHealingWrapper');
const resilientFetch = withSelfHealing(fetch, { maxRetries: 1 });
```

## 4. 适配器网关 + 断路器

### 一句话定义
**外部依赖抽象为可替换适配器,故障自动隔离+恢复。**

### 架构
```
Request → Gateway → Adapter Pool
                     ├── Claude ──── 健康 ✅
                     ├── OpenAI ──── 冷却中 ⏸
                     ├── Ollama ──── 断开 ❌
                     └── Fallback ── 就绪 ✅
```

### 断路器状态机
```
CLOSED(正常) → 连续失败 5 次 → OPEN(断开)
                                      ↓
                               30s 后 → HALF_OPEN(探测)
                                      ↓
                          成功 → CLOSE    失败 → OPEN
```

## 5. 显式层级 + 单向依赖

### 一句话定义
**每层只调用下层,绝不反向;层级边界机器强制。**

### L0-L6 层级规范

| 层 | 目录 | 职责 |
|----|------|------|
| L0 | `kernel/` | 手写 OS 内核 |
| L1 | `platform/` | Python 启动器 |
| L2 | `services/` | Node 业务逻辑 |
| L3 | `apps/` | 管理前端 |
| L4 | `software/` | 内置应用(khyquant) |
| L5 | `extensions/` | 可卸载拓展 |
| L6 | `tools/` | 开发工具 |

### 依赖规则
- 只能向下依赖(L2 → L1 → L0)
- 不能向上依赖(L0 不依赖 L1)
- 不能跨层(L2 不直接依赖 L4)

## 6. 错误归一 + 诚实措辞

### 一句话定义
**内部错误归一为统一形状,对外展示用户可行动的诊断。**

### 标准错误契约
```javascript
{
  ok: false,
  error: {
    code: 'E01',          // 稳定错误码
    type: 'parse_error',  // 分类
    message: '具体错误:...', // 用户可读
    retryable: true,      // 是否可重试
    cause?: Error,        // 原始错误(调试用)
  }
}
```

### 错误码表
| 码 | 含义 | 可重试 |
|----|------|--------|
| E01 | 模型静默空响应 | ✅ |
| E02 | 内容安全拦截 | ❌ |
| E03 | 上下文溢出 | ❌ |
| E04 | 工具执行崩溃 | ❌ |
| E05 | 依赖缺失 | ✅ |
| E06 | 网络/服务端 | ✅ |
| E07 | 权限拦截 | ❌ |
| E08 | 格式校验失败 | ✅ |

## 7. 配置门控 + 字节回退

### 一句话定义
**新功能默认关闭,开启即生效,关闭即逐字节回退到改动前。**

### 模式
```javascript
// 默认开,仅显式 falsy 关闭
if (flagRegistry.isFlagEnabled('KHY_NEW_FEATURE', process.env)) {
  // 新功能(增量)
}
// 门关时,下面代码完全不执行 = 字节回退
```

### Flag 注册
```javascript
// flagRegistry.js
KHY_NEW_FEATURE: { mode: 'default-on', off: 'CANON', default: true }
```

### 适用场景
- 所有新功能上线
- 高风险重构
- A/B 测试
- 灰度发布

## 设计哲学之间的关系

```
                    ┌─────────────────┐
                    │  配置门控 + 字节回退  │
                    │  (安全上线新能力)    │
                    └────────┬────────┘
                             ↓
                    ┌─────────────────┐
                    │  显式层级 + 单向依赖  │
                    │  (可控的复杂度)      │
                    └────────┬────────┘
                             ↓
         ┌───────────────────┼───────────────────┐
         ↓                   ↓                   ↓
┌─────────────────┐ ┌─────────────────┐ ┌─────────────────┐
│  纯叶子模式      │ │  防御纵深        │ │  自愈优先于报错  │
│  (可测、可复用)  │ │  (多层保护)      │ │  (瞬时自愈)     │
└─────────────────┘ └─────────────────┘ └─────────────────┘
         ↓                   ↓                   ↓
         └───────────────────┼───────────────────┘
                             ↓
                    ┌─────────────────┐
                    │  错误归一 + 诚实措辞  │
                    │  (统一的对外契约)    │
                    └─────────────────┘
                             ↓
                    ┌─────────────────┐
                    │  适配器网关 + 断路器  │
                    │  (外部依赖可控)      │
                    └─────────────────┘
```
