协议速查#

⚠️ 本节 2026-09-15 更正。 原「A2A 协议速查」把 khy-os 的私有进程内 ACP 方言
写成了标准 A2A，且方法族（a2a.discovery.* / a2a.capability.* / a2a.task.* /
a2a.status.*）在实现中零存在 —— 属设计草案遗留，从未落地。
术语区分见 [DESIGN-NAM-002]。

私有 ACP（进程内 agent 编排）#

作用域：单进程内。不是对外协议，不要用它对接外部系统。

类型方法说明
Agentagent.spawn / agent.kill / agent.status起停子 agent、查询状态
任务task.submit / task.result / task.progress提交任务、回传结果、上报进度
上下文context.share共享上下文
工具tool.invoke / tool.result请求对端调工具并回传结果
消息message.send / message.broadcast点对点 / 广播
保活heartbeat心跳

真源：services/backend/src/services/acpTransport.js 的 ACP_METHODS 与
services/backend/src/contracts/acp/acp-message.schema.json；
规范文档 [DESIGN-A2A-001]（含定位更正横幅）。

标准 A2A（对外互操作）#

作用域：跨厂商、跨网络。这是唯一可用于对接外部 agent 的协议。

项值
协议版本0.3.0（agentCardSpec.A2A_PROTOCOL_VERSION）
发现GET /.well-known/agent-card.json（公开、无鉴权）
传输JSON-RPC 2.0 over HTTP + SSE（不是 WebSocket）
方法message/send、message/stream、tasks/get、tasks/cancel、tasks/pushNotificationConfig/*
任务状态submitted / working / input-required / completed / canceled / failed / rejected / auth-required / unknown
契约services/backend/src/contracts/a2a/*.schema.json
规范文档[DESIGN-A2A-002] A2A 标准协议适配规范

当前能力（诚实声明）：streaming: false、pushNotifications: false、
stateTransitionHistory: false —— 三项均未实现，故不在卡片上虚报。
真源 agentCardSpec.IMPLEMENTED_CAPABILITIES，由 npm run check:protocol-conformance 实测。

校验命令#

npm run check:protocol-conformance   # 声明 ↔ 实现一致性（MCP + A2A）
npm run check:protocol-naming        # 命名纪律（A2A vs ACP）

通信协议速查#

HTTP 响应格式#

成功响应：

{
  "success": true,
  "data": {},
  "message": "操作成功",
  "pagination": {
    "page": 1,
    "pageSize": 20,
    "total": 100
  }
}

错误响应：

{
  "success": false,
  "message": "错误描述",
  "error": {
    "code": "ERROR_CODE",
    "type": "ERROR_TYPE",
    "details": {}
  }
}

WebSocket 消息格式#

{
  "type": "request|response|event|ping|pong",
  "id": "msg-uuid",
  "method": "service.action",
  "params": {},
  "result": {},
  "error": null
}

SSE 消息格式#

event: message_type
id: event-uuid
data: {"key": "value"}

代码规范速查#

JavaScript/TypeScript#

// ✅ 正确
const userName = 'john';
const MAX_RETRIES = 3;

function getUserById(userId) {
  // ...
}

// ❌ 错误
const user_name = 'john';  // 应该用 camelCase
const max_retries = 3;     // 应该用 camelCase

Python#

# ✅ 正确
user_name = 'john'
max_retries = 3

def get_user_by_id(user_id):
    # ...

# ❌ 错误
userName = 'john'  # 应该用 snake_case
maxRetries = 3     # 应该用 snake_case

文件命名#

# ✅ 正确
user-service.js
user_service.py
UserProfile.tsx

# ❌ 错误
UserService.js      # 应该用 kebab-case
user-service.py     # 应该用 snake_case
userprofile.tsx     # 应该用 PascalCase

版本管理#

语义化版本：MAJOR.MINOR.PATCH

  • MINOR：向下兼容的功能性新增
