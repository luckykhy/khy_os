[DESIGN-ARCH-090] TUI 用户评价调研与痛点分析#

隶属：本文属 TUI 设计族（20 编号 / 21 文件），总纲与 scope 裁决见 [DESIGN-ARCH-122] TUI 设计族总纲；规则冲突一律以 [DESIGN-ARCH-102] Khy TUI 统一规则手册 为准。

定位：基于用户 Issue、社区讨论、评测文章的 TUI 痛点分析，指导设计改进。
调研来源：Claude Code Issues (5k+)、HN 讨论、Reddit、技术博客、GitHub 100+ 项目。

1. Claude Code 官方 Issue 分析#

1.1 TUI 相关高投票 Issue#

Issue #3648: Terminal Scrolling Uncontrollably#

问题：终端在 Claude Code 交互期间不受控制地滚动。
用户反馈：

  • "Claude Code 输出时终端疯狂滚动，我无法查看之前的输出"
  • "流式输出时我的终端滚动到了顶部，丢失了上下文"

根因：Ink 的滚动区处理与终端滚动历史的冲突。
我们的方案：

  • 使用 ED0 而非 ED2 清除
  • 保存/恢复光标位置
  • 局部更新不触发全终端滚动

Issue #826: Console Scrolling Top of History#

问题：Claude 向控制台添加文本时滚动到历史顶部。
用户反馈：

  • "每次 Claude 输出新内容，我的视图都会跳到顶部"
  • "我无法在 Claude 输出时保持我的滚动位置"

根因：全屏重绘导致终端滚动。
我们的方案：

  • <Static> 组件缓存已提交消息
  • 仅重绘变化的区域
  • 不触发全终端刷新

3.2 最佳实践提炼#

滚动最佳实践（来自 lazygit/k9s）#

1. 分页滚动而非平滑滚动（减少闪烁）
2. 保持选中行在可见范围内
3. 滚动时显示位置指示器（如 "3 of 48"）
4. 上下方有更多内容时显示 "⋯" 标记

复制最佳实践（来自 OSC 52 社区）#

1. 优先使用 OSC 52（支持 SSH）
2. 提供系统命令 fallback（pbcopy/xclip/clip）
3. 复制后显示反馈（copied N chars）
4. 复制值而非渲染内容（无截断/填充）

历史最佳实践（来自 atuin/fzf）#

1. ↑↓ 在输入框内浏览历史
2. 未发送文本保留在输入框
3. 历史持久化到磁盘
4. 支持搜索过滤（Ctrl+R）
5. 去重 + 容量限制（~100 条）

4. 我们的改进方案#

4.1 滚动不干扰选择/复制/历史#

核心原则：模式分离

浏览模式（默认）
  ├─ ↑/↓: 浏览历史输入
  ├─ PgUp/PgDn: 滚动对话区
  └─ 不影响选择状态

选择模式（v 进入）
  ├─ ↑/↓: 移动选择光标
  ├─ Space: 标记/取消
  └─ Enter: 确认选择

历史模式（Ctrl+R）
  ├─ 输入: 过滤历史
  ├─ ↑/↓: 导航结果
  └─ Enter: 选中历史

复制模式（c 进入）
  ├─ ↑/↓: 选择复制范围
  └─ Enter: 执行复制

4.2 模型跑偏处理#

检测层：
  ├─ 重复工具调用计数
  ├─ 执行超时检测
  ├─ Token 消耗速率异常
  └─ 权限拒绝频率

响应层：
  ├─ 自动暂停（严重时）
  ├─ 警告提示（中等）
  └─ 记录日志（轻微）

恢复层：
  ├─ 用户输入引导
  ├─ 回滚到检查点
  ├─ 切换模型/通道
  └─ 新建对话

4.3 错误消息模板#

格式：{问题一句话}：{原因}，{修复建议}

示例：
  ✗ 工具执行超时：命令运行超过 30 秒，增加超时时间或拆分任务
  ✗ 上下文溢出：对话过长，运行 /compress 压缩或新建会话
  ✗ 模型无输出：可能端点错误/模型名无效/额度不足，运行 khy gateway status 检查
  ✗ 权限被拒绝：用户取消授权，重新执行以授权
  ✗ 循环检测：同一工具调用 5 次，中断并检查任务定义

5. 验证清单（用户视角）#

5.1 首次使用体验#

  • [ ] 启动后 3 秒内看到欢迎界面
  • [ ] 帮助菜单（?）清晰可用
  • [ ] 输入框有明确的占位符
  • [ ] 底部提示栏显示常用快捷键

5.2 日常使用体验#

  • [ ] 滚动流畅，不跳来跳去
  • [ ] 复制有明确反馈
  • [ ] 历史输入易于回溯
  • [ ] 错误消息包含修复建议
  • [ ] 中断操作即时响应

5.3 异常处理体验#

  • [ ] 工具失败有重试/跳过选项
  • [ ] 模型跑偏可中断和纠正
  • [ ] 上下文溢出有明确提示
  • [ ] 网络断开自动重连

5.4 高级功能体验#

  • [ ] 命令面板易于发现
  • [ ] 分叉/撤销操作直观
  • [ ] 右侧看板信息丰富
  • [ ] 设置变更即时生效

6. 优先级排序#

P0（必须解决）#

  1. 滚动/选择/历史/复制模式分离
  2. OSC 52 剪贴板 + 字符反馈
  3. 模型跑偏检测 + 用户引导
  4. Ctrl+C 双击退出 + 中断
  5. 错误消息包含修复建议

P1（应该解决）#

  1. 命令面板（Ctrl+P）
  2. 历史搜索（Ctrl+R）
  3. 检查点回滚
  4. Token 用量警告
  5. 权限模式切换反馈

P2（可以解决）#

  1. 右侧看板
  2. 多代理视图
  3. 主题切换
  4. 会话恢复提示
  5. 语音输入反馈
