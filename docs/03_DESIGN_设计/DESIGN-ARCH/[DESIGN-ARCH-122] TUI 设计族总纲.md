## 3. Scope 裁决（重叠即归口，依据 `[MGMT-STD-008]` §2.2）

- **规则真源 = 102**：`079` 已显式降级为历史详表；`103` 是重设计方案（演进方向），不替代 102。
- **组件设计（082–088）彼此不重叠**，各管一类组件，无需合并。
- **119 同号双文件**是已知编号碰撞（本族唯一），两篇职能不同，保持分离。
- `129` 与 `119` **不重叠**：`119` 是「修复方案 + 验收标准」（怎么修、修到什么程度），`129` 是「共存机制 + 代价清单」（为什么能共存、代价是什么）。两者互为引用，**勿合并**。
- 本族与 `[DESIGN-ARCH-016] AI Agent 显示规范`、`[DESIGN-ARCH-078]` 桌面端互联方案**边界清晰**：本族只管 TUI 设计，互不覆盖。
