约束#

错误响应必须提供稳定机器码 + 人类消息；SSE/WS 终态必须区分 done/degraded/cancelled/failed 四态且互斥；upstream 异常后不得发送成功完成标记。

授予权力#

见约束边界：授权按统一信封构造错误响应，四终态择一。

提供福利#

客户端可按机器码自动处理、按人类消息直接展示，不必解析自然语言。

反例#

upstream 异常后仍发送 stop 与成功完成标记。
