约束#

索引文件的命名格式、前缀与编号体系严禁在本规范及任何系统提示词中写死；执行 AI 必须先读取目录现有文件序列，自行决策最合理方案，只需满足「排序绝对首位」与「逻辑连贯」两项硬约束。

授予权力#

授权执行 AI 依目录惯例自行决定索引文件名，无需事前请示。

提供福利#

不必先查一条固定格式规定；跨目录惯例自然延伸，不会与既有命名冲突。

反例#

在规范里写死 00_INDEX_* 的具体命名形态，导致每次新增目录都要改规范。

校验方式#

人工评审（[MGMT-STD-001] §2.3 追加的管辖边界条款）

例外#

业务文档编号前缀不在本条管辖，归 DOCS-001（裁决 X-001 按 scope 分层）。
