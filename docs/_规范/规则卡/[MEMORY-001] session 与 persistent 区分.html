约束#

仅当前任务需要且无需跨会话复用的信息归 session；跨会话稳定事实才归 persistent。

授予权力#

见约束边界：授权按 ACP context.share.scope 声明作用域。

提供福利#

不必为「该不该记住」逐条争论；一次性输出不会污染长期记忆。

反例#

把一次性命令输出写入长期项目记忆。
