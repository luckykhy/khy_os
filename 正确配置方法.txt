        Khy-OS 全局命令 - 正确配置方法
═══════════════════════════════════════════════════════════════

🎯 方法 1：PowerShell 一行命令（完整版）
───────────────────────────────────────────────────────────────

打开 PowerShell，复制粘贴下面这一整行：

if(!(Test-Path $PROFILE)){New-Item -ItemType File -Path $PROFILE -Force|Out-Null};Add-Content $PROFILE "`nfunction khy{node C:\khy-os\services\backend\bin\khy.js `$args}";.$PROFILE;khy --version

⚠️ 确保复制完整！最后有 ";.$PROFILE;khy --version"

───────────────────────────────────────────────────────────────

🎯 方法 2：分步手动配置（推荐，最可靠）
───────────────────────────────────────────────────────────────

1. 在 PowerShell 中运行：
   notepad $PROFILE

2. 如果提示文件不存在，点击"是"创建

3. 在打开的记事本中添加这一行：
   function khy { node C:\khy-os\services\backend\bin\khy.js $args }

4. 保存并关闭记事本

5. 在 PowerShell 中运行：
   . $PROFILE

6. 测试：
   khy --version

✅ 完成！

───────────────────────────────────────────────────────────────

🎯 方法 3：立即使用（无需配置）
───────────────────────────────────────────────────────────────

cd C:\khy-os
.\khy.bat --version
.\khy.bat --help
.\khy.bat

✅ 这个方法最简单，立即可用！
