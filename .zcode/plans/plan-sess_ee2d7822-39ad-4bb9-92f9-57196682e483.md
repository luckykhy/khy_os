# 命令自注册系统 — 渐进迁移方案

## 目标

新增命令从「改 6 处文件」降为「创建 1 个 handler 文件」，彻底消除 router.js 巨型 switch 的维护痛点。渐进迁移，现有命令零改动。

---

## 改动清单（按执行顺序）

### 1. 新建 `services/backend/src/cli/commandManifest.js` — 清单 schema 与校验

**职责**：定义命令清单的数据结构、校验常量、校验函数。

导出：
- `MANIFEST_EXPORT_KEY = '__khyCommandManifest'` — handler 导出清单时使用的键名
- `validateManifest(manifest)` — 校验清单必填字段（`name`、`handler`），返回 `{ valid, errors }`
- 常量 `DEFAULT_CATEGORY = 'extension'`、`HANDLERS_DIR` 路径

清单 schema：
```js
{
  name: 'health',              // 规范命令名（必填）
  aliases: ['jk', '健康'],      // 可选别名
  description: '聚合健康诊断',   // help 显示
  usage: 'health [--json]',     // 用法行
  subCommands: [],              // 可选子命令列表
  category: 'system',           // 分类（可选）
  async handler(parsed, context) {}  // 分发函数（必填）
}
```

---

### 2. 新建 `services/backend/src/cli/commandAutoRegistry.js` — 自动发现与分发

**职责**：扫描 handlers/ 目录，构建命令分发表，提供分发入口。

核心导出：
- `init()` — 扫描 `handlers/` 下所有 `.js` 文件，导入模块，检测 `module.exports[MANIFEST_EXPORT_KEY]` 或 `module.exports.commandManifest`，校验后注册
- `dispatch(command, parsed, context) → { handled: boolean, result: any }` — 查找命令并调用 handler；未找到返回 `{ handled: false }`
- `getCommandNames() → string[]` — 返回所有已注册命令名（供 commandSchema 未来消费）
- `getAliases() → { alias: command }` — 返回所有别名映射（供 aliases.js 未来消费）
- `getCompletions() → [{ name, description, usage }]` — 供 help/Tab 使用

关键设计：
- 使用 `fs.readdirSync` 扫描 handlers/ 目录
- 跳过 `_` 前缀的私有模块（如 `_portableAutoInstall.js`）
- 每个 handler 的清单通过懒加载导入，不增加启动开销
- 重复注册时 warning 并跳过（fail-soft）

### 3. 修改 `services/backend/src/cli/router.js` — 接入自注册分发

**改动位置**：`route()` 函数内，在三个 dispatch cluster 之后、主 switch 之前（约 line 969）。

**改动内容**（约 15 行）：
```js
// Auto-registered commands (progressive migration)
{
  const autoResult = await commandAutoRegistry.dispatch(command, {
    subCommand, args, options, rawCommandToken, parsed, context,
    printError, printHelp, printInfo, printTable, printSuccess, printWarn, withSpinner, chalk,
  });
  if (autoResult.handled) return autoResult.result;
}
```

**效果**：自注册命令优先于硬编码 switch 执行。未迁移的命令仍走 switch，零风险。

### 4. 示范迁移：`handlers/health.js` — 清单导出

**改动**：在现有 `module.exports = { handleHealth, collectHealth, _bytesHuman }` 上新增清单导出：

```js
const { MANIFEST_EXPORT_KEY } = require('../commandManifest');
module.exports[MANIFEST_EXPORT_KEY] = {
  name: 'health',
  aliases: ['jk', '健康'],
  description: '聚合运行时/数据/认证/网络/磁盘/内存健康信号到一份可操作报告',
  usage: 'health [--json]',
  category: 'system',
  handler: handleHealth,
};
module.exports.handleHealth = handleHealth;
module.exports.collectHealth = collectHealth;
module.exports._bytesHuman = _bytesHuman;
```

**注意**：router.js 中 `case 'health'` 分支**暂时保留**，作为回归测试对比基准。确认自注册路径 100% 后再清理。
